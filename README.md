# terra-cube

An experiment: a voxel sandbox game in Rust (Bevy), with every creature in it generated and animated by a pipeline an agent can drive.

- [AGENTS.md](AGENTS.md): the map, the commands, the rules.
- [docs/engine.md](docs/engine.md): what was decided and why.
- [docs/pipeline.md](docs/pipeline.md): making a creature.
- [docs/art-guide.md](docs/art-guide.md): how things should look.

```bash
make          # checks this machine is set up
make help     # lists the commands
make play     # the island and its creatures, as the player
make run      # the sandbox, one of each creature to pose
```
